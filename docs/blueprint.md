# **App Name**: NziklèZoun

## Core Features:

- Subject Input: Allows the user to input a subject (e.g., 'photosynthesis') for generating an educational video script via a form.
- Script Generation: Generates a structured educational video script based on the user-provided subject, using a generative AI tool. The script includes sections for the title, introduction, key points, a practical example, a conclusion, and visual suggestions.
- Structured Script Display: Displays the generated video script in a structured and easily readable format.
- Script Validation: Allows the user to validate (accept) the generated script, triggering the video generation process.
- Video Generation: Generates a video based on the validated script by automatically sending it as a prompt to a video generation API. Uses a generative AI tool.
- Video Link Retrieval: Retrieves the generated video link or URL, making it accessible to the user.

## Style Guidelines:

- Primary color: Deep blue (#3F51B5) to convey trust and knowledge.
- Background color: Light gray (#F0F0F0) for a clean and unobtrusive backdrop.
- Accent color: Orange (#FF9800) to highlight important elements and call-to-actions.
- Body and headline font: 'PT Sans', a humanist sans-serif for a modern look and legibility.
- Use simple and clear icons to represent different sections or features (e.g., play icon for video, pen icon for script editing).
- Maintain a clean and structured layout to improve readability. Use clear section headings and whitespace effectively.
- Incorporate subtle animations for user feedback and to indicate loading or processing states. Keep animations short and purposeful.
